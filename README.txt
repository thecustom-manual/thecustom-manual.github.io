더커스텀 교육 매뉴얼 2차

- 총 화면: 37
- 최종 평가: 20문항 / 18문항 이상 정답 수료
- 모든 화면: 나레이션 완료 전 다음 페이지 이동 불가
- 실습 화면: 나레이션 완료 후 실습까지 통과해야 이동 가능
- 태블릿: 설명 단원만 유지, 별도 태블릿 실습 없음
- 정적 SPA: /1page, /2page 같은 URL 라우팅을 사용하지 않음
- 진행도: Web Crypto AES-GCM으로 암호화 저장(정적 사이트 특성상 완전한 보안 기능은 아님)
- 예상 나레이션 길이: 약 54.6분(분당 410자 가정)
- 다단계 실습 및 20문항 평가를 포함한 전체 예상 이수 시간: 60분 이상

실행: index.html을 열거나 python -m http.server 8080 실행 후 http://localhost:8080 접속

ElevenLabs 음성 파일은 audio/page-01.mp3 형식으로 넣으면 자동 사용합니다. MP3가 없으면 브라우저 한국어 TTS로 대체됩니다.
